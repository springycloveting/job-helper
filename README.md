# 求职助手 - 智能岗位筛选浏览器插件

在招聘平台上智能过滤高风险岗位、评估岗位匹配度、生成简历优化建议。

## 功能特性

### 🔍 三层智能筛选

1. **过滤层** - 本地规则粗筛 + LLM精筛，识别诈骗/高风险/虚假岗位
   - 高风险关键词检测（轻松月入、培训费、刷单等）
   - 薪资异常检测（范围过宽、明显虚高）
   - 公司信息缺失检测
   - LLM深度分析隐藏风险信号

2. **匹配层** - 基于简历的岗位匹配度评分
   - 技能匹配、经验匹配、学历匹配
   - 标注关键匹配项和缺失项
   - 匹配度过低自动建议跳过

3. **优化层** - AI生成针对性简历修改建议
   - 突出与岗位匹配的技能和经验
   - 一键生成针对性简历（Markdown格式）
   - 支持导出 Word / PDF

## 安装使用

### 1. 安装插件

**从源码安装（开发者模式）：**

1. 克隆仓库
   ```bash
   git clone https://github.com/yourname/job-helper.git
   ```
2. 打开浏览器扩展管理页面（Edge: `edge://extensions/`，Chrome: `chrome://extensions/`）
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `src/` 目录

### 2. 配置 API

1. 点击插件图标 → 设置
2. 填写 API 配置：
   - **API Key** - 你的大模型 API Key
   - **API Base URL** - API 地址，如 `https://api.openai.com/v1`
   - **模型名称** - 如 `gpt-3.5-turbo`、`deepseek-chat`
3. 点击「测试连接」验证配置
4. 保存配置

### 3. 填写简历

1. 在设置页切换到「简历信息」标签
2. 粘贴你的简历内容（建议包含：基本信息、工作经历、技能特长、项目经验）
3. 保存简历

### 4. 开始使用

1. 访问 [Boss直聘](https://www.zhipin.com) 或 [拉勾网](https://www.lagou.com)
2. 搜索职位，进入岗位列表页
3. 每个岗位卡片右侧会出现紫色的「🔍 分析」按钮
4. 点击按钮即可分析岗位
5. 在岗位详情页，可点击浮动按钮进行更详细的分析

## 技术架构

```
用户操作                    Content Script              Service Worker           大模型 API
─────────                   ──────────────              ──────────────           ──────────
访问招聘页面 ──→ 检测平台 & 注入分析按钮
                              │
点击「分析」 ──→ 提取岗位信息
              │               │
              │        本地规则粗筛（无需API）
              │               │
              │        粗筛通过 → 发送消息 ──────→ 调用LLM API ──────→ 风险分析
              │               │                        │
              │               │     ←── 返回分析结果 ←──┘
              │               │
              │        有简历 → 发送消息 ──────→ 调用LLM API ──────→ 匹配评分
              │               │                        │
              │        显示结果面板                     │
              │               │
点击「详情」 ──→ 弹出详细分析弹窗
              │
点击「生成简历」→ 发送消息 ──────→ 调用LLM API ──────→ 简历生成
                              │                        │
                              │     ←── 返回简历内容 ←──┘
                              │
                        渲染Markdown → 支持导出Word/PDF
```

### 设计要点

- **本地粗筛优先**：高风险关键词和薪资异常先由本地规则判断，不消耗 LLM 算力
- **串行分析**：批量分析时逐个串行请求，避免并发超出模型承受
- **精简上下文**：岗位信息提取摘要而非全文，简历截断到 800 字，避免超出模型上下文窗口
- **安全存储**：API Key 和简历仅存储在浏览器本地 `chrome.storage`，不上传任何服务器

## 常见问题

**Q: 点击分析按钮没反应？**
A: 请检查：1) 是否已配置 API Base URL；2) 是否刷新了招聘平台页面；3) 控制台是否有报错。

**Q: 分析结果不准确？**
A: 建议使用更强的模型（如 GPT-4、DeepSeek-V3），弱模型在风险识别和匹配分析上效果较差。

**Q: 支持 Chrome 吗？**
A: 支持。本插件基于 Manifest V3，兼容 Chrome 和 Edge。

**Q: 我的 API Key 安全吗？**
A: API Key 仅存储在浏览器本地，仅在调用大模型 API 时使用，不会上传到任何第三方服务器。

## 开发

### 调试

在招聘平台页面按 F12 打开控制台，可查看插件运行日志。

### 修改适配

如需适配新的招聘平台，需修改以下位置：

1. `manifest.json` - 添加 `host_permissions` 和 `content_scripts.matches`
2. `content/content.js` 中的 `detectPlatform()` - 添加域名检测
3. 新增 `extractXxxJobInfo()` 函数 - 提取岗位信息
4. `observeJobCards()` 中的 `selectors` - 添加岗位卡片选择器
5. `injectDetailPageButton()` - 添加详情页URL检测
