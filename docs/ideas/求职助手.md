# 求职助手

## Problem Statement
我们如何帮助求职者在招聘平台推荐的岗位中，快速识别和过滤高风险/不合适岗位，并精准评估自身与剩余岗位的匹配度，从而提升求职效率和成功率？

## Recommended Direction

**招聘平台的"智能过滤器"——二次筛选 + 匹配评分 + 简历优化**

求职者每天在招聘平台上收到大量推荐岗位，但其中混杂着诈骗岗位、挂羊头卖狗肉的岗位、以及与自己背景严重不匹配的岗位。现有平台没有动力帮你过滤（他们要的是点击量和投递量）。

我们的产品站在求职者这边：
1. **过滤层**：识别并过滤诈骗/高风险/虚假岗位（薪资虚高、公司信息异常、岗位描述模糊等红旗信号）
2. **匹配层**：对通过过滤的岗位，基于用户简历进行匹配度评分，标注关键匹配项和缺失项
3. **优化层**：针对高分岗位，AI生成简历修改建议，让用户的简历更有针对性

产品形态：先做浏览器插件/小程序，用户在招聘平台浏览岗位时，插件实时显示过滤结果和匹配评分。后续扩展为Web/App。

## Key Assumptions to Validate
- [ ] 求职者对"岗位筛选"有足够强的付费意愿（vs 免费使用招聘平台自带功能）—— 通过早期用户访谈验证
- [ ] 诈骗/虚假岗位的识别准确率可以达到用户信任的水平（80%+）—— 用标注数据集测试分类模型效果
- [ ] 匹配度评分比招聘平台自带的"匹配度"更有价值—— 让用户盲评两套评分，看哪个更准确
- [ ] 用户愿意上传简历并连接招聘平台—— 先做无需登录的手动输入版本测试使用率

## MVP Scope

### 在范围
- 浏览器插件：在Boss直聘/拉勾等平台页面上叠加显示
- 诈骗/高风险岗位识别（基于大模型的语义分析，识别岗位描述中的红旗信号）
- 简历-岗位匹配度评分（基于大模型的语义匹配，理解简历和岗位的深层含义，而非简单关键词比对）
- 针对目标岗位的简历修改建议（大模型生成针对性修改建议）
- 手动输入简历信息（MVP阶段不要求连接账号）
- 插件设置页：用户自行填写OpenAI格式的API Key和Base URL，应用通过用户自有的大模型API进行语义分析，无需后端服务

### 不在范围
- 连接招聘平台账号自动抓取（MVP后）
- 全量岗位搜索和推荐（不做招聘平台的事）
- 简历模板库（后续考虑）
- 面试准备功能（后续考虑）
- 移动端App（先做插件验证）

## Not Doing (and Why)
- **不做全量岗位推荐** —— 这是招聘平台的核心功能，我们没有数据优势，且与平台直接竞争
- **不做简历模板** —— 现有工具（超级简历等）已做得很好，不是我们的差异化
- **不做薪资分析** —— 数据获取难，且与核心流程无关
- **不做社交/社区功能** —— 分散焦点，MVP阶段不需要
- **不做自动投递** —— 求职者需要掌控投递决策，自动投递风险高
